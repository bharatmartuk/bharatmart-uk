## How to use (ChatGPT)

1. Open ChatGPT (GPT-4o / image-capable model preferred).  
2. Upload the **BharatMart logo** (PNG with transparent background if possible).  
3. Paste the entire prompt from the fenced block above.  
4. Add one short extra line at the end if needed:

```text
Use the attached image only inside the [LOGO] slot. Do not redesign the logo.
```

5. After generation, edit in Canva/Figma:
   - Replace `[INTERN FULL NAME]`
   - Replace `[CERTIFICATE ID]` (e.g. `BM-INT-2026-001`)
   - Add signature + authorised signatory name
   - Fill date of issue
